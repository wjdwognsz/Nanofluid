# 이번 세션에서 실제로 계산한 공개 데이터 PoC 결과 (GitHub에서 내려받아 실행; RF 기반 예비값)

E1 출처(논문) 효과: Cogni-e-SpinDB(809건/57편/12고분자) log10 섬유직경. 무작위 5-fold RMSE 0.18(R²≈0.72) vs 논문 단위 분할 0.35(R²≈0.0, 평균 예측 0.345와 동일) vs 고분자 단위 0.39. 공정변수만으로 출처 논문 식별 정확도 0.99(PVDF 17편; 다수결 0.19). 서로 다른 논문의 거의 같은 조건(농도±1wt%, 전압±2kV, 유량±30%, 거리±2cm) 51쌍의 직경 차이 중앙값 1.55배.
E2 앵커(기준시료) 보정: 새 논문에서 k점만 받아 출처 오프셋 보정 시 R² −0.00/0.07/0.27/0.33 (k=0/1/2/3), MAE 0.274→0.195 (두 에이전트 독립 재현: 0.14→0.36@k=3).
E3 조건 조화: polyVERSE H2O 확산계수, 같은 고분자가 온도·수분활동도 조건에 따라 중앙값 3.6배(최대 300배) 차이. 공통 Arrhenius+활동도 보정으로 엄격 LOO MAE 0.368→0.291 log10(−21%).
E4 데이터 감사: polyVERSE 기체 P-D-S 550/550건이 P=D·S를 정확히 만족(한 값은 파생값; 독립 라벨 아님); 물 활동도>1 18행(물리적 불가); 실험 레코드 98%가 Temp=298.00K(기본값 의심); Cogni-e-SpinDB 습도 45%가 57편 중 33편(444행)이며 온도 결측 214행 전부 45%(기본값 대입 의심); 농도 단위 wt% 735 / w/v% 74 혼재.
E5 공개 DB 간 가상 라운드로빈: 기체투과 DB 4~5종(polyVERSE, Yang2022 SciAdv, PoLyInfo-Kaggle 미러, GREA, NETL) 같은 고분자 값의 75~98%가 '정확히 동일'(같은 원천 복사 → 독립 정보 아님, 데이터 계보 문제); 다른 원천을 쓴 Yang2022와는 10~19%가 2배 이상 차이, 1~3%는 10배 이상. Tg: DB마다 °C/K 혼재, 독립 출처 간 15~18%가 10K 이상 차이(σ_R≈21K).
E6 계통수(참가자 제안) 검증: (a) 기술적 수준 — 기체투과 6종에서 계통수 거리가 분자지문 거리 이상의 정보(부분 Spearman 0.12~0.20, 순열 p≤0.005; 클레이드 η² 0.47~0.50 vs 무작위 0.04). 단 트리 거리 1(같은 계열·불소 유무 다름)이 거리 2보다 차이가 커 단조성 깨짐. (b) 예측 수준 — 계열 하나를 통째로 뺀 소수샷(k=0/3/5/10)에서 트리 계층 부분풀링 = 평평한 부분풀링(차이 95%CI가 0 포함), 지문유사도 사전이 k=0에서 트리보다 우수(−0.022 RMSE, CI 0 미포함), 트리 one-hot 특성은 k=10에서만 −1.4%. 전기방사: 트리 기반 학습데이터 선택 ≈ 무작위 선택 ≈ 지문 최근접(차이 <2%), 트리를 두 가지(유래 우선 vs 용매 우선)로 바꾸면 결과가 달라짐.
E7 실패 데이터: Cogni-e-SpinDB PVDF(실패 32건/10편) 실패 논문 하나 빼기에서 성공만 학습한 one-class 모델 AUC 0.23~0.32(무작위보다 나쁨) vs 실패 포함 지도학습 0.71~0.74. 실패 조건은 '전형적' 조건(15wt%, 15kV, 15cm).
E8 전이/징검다리(진행 중 일부): 영구기체끼리 logP 상관 0.93~0.99 vs H2O–O2 0.26. H2O 투과(27종) 타깃: 최고 점수 직접 소스 이득 미미, B(s_exp_CH4) 직접 −11.6% RMSE, A→B→C 체인은 B 직접보다 나쁨. H2O 확산(45종): 체인 0.706 vs B 직접 0.712 vs 기준 0.750(차이 미미). 다른 에이전트 설정에서는 H2O 투과 타깃에 8개 소스 모두 음전이(최대 −17%). 물리적으로 무관해 보이는 DFT 밴드갭 소스가 H2O 용해(25종)에서 큰 이득을 보인 사례가 있어 소표본 다중비교 착시 가능성 점검 중. 전기방사 8-shot 고분자 간 전이: PVDF→PVA 이득 −0.084(양수 3%), PVA→PVDF +0.130(90%)로 비대칭.
