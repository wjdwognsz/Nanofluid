## 0. 결론 요약

**추천 컨셉: "가상 라운드로빈(Virtual Round-Robin)" 기반 섬유 소재데이터 신뢰·합류 체계**

부제는 "AI는 소재가 아니라 '출처'를 배우고 있다. 출처를 아는 소재데이터로 바꾸자"입니다.

여러 연구실·논문·시험기관에서 쌓인 섬유 소재데이터를 "계획되지 않은 실험실간 비교시험(round-robin)"으로 다시 읽는 아이디어입니다. 다음 네 단계를 하나의 체계로 묶습니다.

1. **레코드 감사**: 파생값, 기본값, 물리 위반, 단위·용어 혼재, DB 간 중복 계보를 찾아냅니다.
2. **출처 효과 분해**: 출처 효과를 분리하고 달성 가능한 정확도의 상한(노이즈 천장)을 계산합니다.
3. **기준시료(앵커) 합류 프로토콜**: 새 기관·기업이 기준시료 3~5점만 측정하면 플랫폼 데이터에 합류할 수 있게 합니다.
4. **실패 데이터 기탁**: 실패 기록을 데이터로 받습니다.

확장 모듈로 두 가지를 둡니다. 하나는 증기 투습 시험법 사이의 환산이고, 다른 하나는 외부 데이터를 연계하기 전에 검증하는 게이트입니다.

## 2. 한 단계 넓혀 보기(step-back): 섬유 소재데이터의 진짜 병목

1. **데이터 양보다 "출처 정보"가 부족합니다.**
   - 섬유 데이터는 시험법(KS/ISO/ASTM/JIS/AATCC), 조건(온습도·활동도·시편 상태), 기관, 장비, 측정자에 따라 값이 달라집니다.
   - 그런데 이런 정보가 기록되지 않거나 기본값으로 채워집니다.
   - 이번 PoC에서 모델은 공정변수만으로 출처 논문을 99% 맞혔습니다(다수결 기준선은 19%). 예측 성능의 상당 부분이 "소재 이해"가 아니라 "출처 식별"이라는 뜻입니다. 다만 이 수치는 논문마다 실험 격자가 달라서 생기는 면이 있으므로, 측정 편향의 직접 증거로 보지는 않습니다.
2. **공개 DB의 수가 독립 정보의 양을 뜻하지 않습니다.** 여러 DB가 같은 원천(PoLyInfo 등)을 복사합니다.
3. **실패는 기록되지 않습니다.** 그래서 "되는 조건"만 학습한 모델은 공정창의 경계를 모릅니다.
4. **연계는 공짜가 아닙니다.** 외부 데이터를 무작정 붙이면 61%가 오히려 성능을 떨어뜨렸습니다(이번 PoC).

이 관점에서 나온 문제 후보는 다음과 같습니다.
- 데이터 신뢰도와 재현성
- 시험법 조화
- 실패 데이터
- 연계 판정
- 규제 대응(PFAS, 미세섬유, 디지털제품여권 DPP)
- 순환(탈색·재생)
- 공정·용매 설계

## 5. 최상의 1개: 완성형 설계 (설명서 한 장 분량)

### 제목
**가상 라운드로빈(Virtual Round-Robin): 출처를 아는 섬유 소재데이터 — 감사·재현성 진단·기준시료 합류·실패 기탁 체계**

### 한 줄 요약
여러 기관·논문·시험법에서 모인 섬유 소재데이터를 "계획되지 않은 실험실간 비교시험"으로 재해석합니다. 그 결과를 세 가지로 만듭니다.
- 데이터마다 붙는 신뢰 라벨
- 새 기관이 기준시료 3~5점으로 플랫폼에 합류하는 규칙
- 실패 기록을 데이터로 받는 양식

### 문제 정의
- **현상**: 섬유 소재데이터는 출처(기관·장비·측정자), 시험법(KS/ISO/ASTM/JIS/AATCC), 조건(온습도·활동도), 계보(복사·재인용)가 기록되지 않은 채 합쳐집니다.
- **결과**: AI 모델은 소재가 아니라 출처를 학습합니다. 무작위로 나눠 검증하면 좋아 보이지만, 새 기관·새 논문 데이터에서는 무너집니다.
  - 전기방사: R² 0.72 → 0.0
  - PLA 염색: R² 0.36 → −0.22
- **용어 설명 — 라운드로빈(round-robin, 실험실간 비교시험)**: 같은 시료를 여러 기관이 측정해 반복성 σr과 재현성 σR을 구하는 절차입니다. ISO 5725에 정의되어 있습니다.
- **'가상'의 의미**: 공통 시료 없이, 이미 쌓인 데이터에서 같은 조건 쌍과 출처 오프셋을 통계적으로 추정한다는 뜻입니다.
- **공인시험기관의 숙련도시험(proficiency testing)과의 차이**: 숙련도시험은 계획된 공통시료가 필요합니다. 이 컨셉은 플랫폼에 이미 쌓인 데이터를 사후에 감사하고 합류 규칙을 만듭니다.

### 방법 (4단계)

**① 레코드 감사(신뢰 라벨)** — 씨앗 (a)의 규칙 필터를 여기서 씁니다.
- 물리 항등식: P=D·S, 질량보존
- 물리 범위: 0≤수분 활동도≤1, 흡진율 0~100%
- 기본값 탐지: 단일 상수 쏠림(예: 습도 45%)
- 단위·용어 표준화: wt%↔w/v%, °C↔K, 중국어 분류 라벨
- 파생값 표시, DB 간 계보 중복 제거
- 산출물: 레코드마다 `측정/파생/기본값/위반/계보ID` 플래그

**② 출처 효과 분해(가상 라운드로빈)**
- 모형: y = f(x) + b_출처 + b_시험법 + ε (혼합효과 또는 계층 베이지안)
- 산출: 출처 간 분산 비중, 같은 조건 쌍의 재현성, 데이터셋별 "달성 가능 정확도(노이즈 천장)"
- 평가는 반드시 출처 단위로 나눕니다(leave-one-source-out).

**③ 기준시료 합류 프로토콜**
- 새 기관·기업이 기준시료 k점을 측정하면 출처 오프셋을 추정해 보정합니다.
- k별 회복 곡선으로 "합류에 필요한 최소 k"를 정합니다. PoC 기준 3~5점입니다.
- 실제 운영에서는 DYETEC의 공인시험·숙련도시험 시료를 물리적 기준시료로 씁니다.

**④ 실패 데이터 기탁**
- 실패·불합격(비드, 미방사, 재염색 로트, 색차 불합격) 필드를 스키마에 넣습니다.
- 실패 포함 여부에 따른 성능 차이를 "실패 1건의 가치"로 공개합니다(정성 크레딧).

**(확장 1) 증기 투습 시험법 등화** — 씨앗 (b)
- 대상: ASTM E96 변형, JIS L1099 A-1/B-1, ISO 11092
- 방법: 다리 시료(같은 직물 다시험법)로 환산식과 불확도를 구합니다.
- 범위: 미세다공·비흡습 직물에 한정합니다.
- 제외: 친수 무공막·Janus 소재와 액체 MMT(AATCC 195)는 "비교 불가" 플래그를 붙이고 별도 축으로 둡니다.

**(확장 2) 연계 게이트** — 씨앗 (c)
- 외부 데이터를 붙이기 전에 타깃 학습데이터로 데이터 기반 사전 점수를 계산합니다. 소스 모델 예측과 타깃 라벨의 상관입니다.
- 소규모 검증을 거쳐 통과한 것만 연계합니다.
- 징검다리 체인은 검증에서 이길 때만 허용합니다.
- 소재 계통수(씨앗 d)는 데이터 커버리지 지도와 시각화에만 씁니다.

### 산출물: 서식 3·4에 담을 '소재데이터'
1. 감사된 공개 데이터셋 3종의 데이터 카드(전기방사, 염색, 기체·수증기 투과). 항목은 출처, 규모, 결측, 기본값, 파생값, 계보, 재현성, 노이즈 천장, 라이선스입니다.
2. 확장 메타데이터 스키마(필드 사전): `source_id, test_standard(+version), conditions, is_reference_sample, is_derived, is_default, failure_flag, lineage_id`
3. k-기준시료 회복 곡선과 합류 규칙 초안
4. (확장) 증기 투습 시험법 환산표 시범판과 "비교 불가" 목록

### 기대 효과
- **기업·플랫폼**:
  - 새 기업 데이터가 기준시료 몇 점으로 플랫폼에 들어올 수 있습니다.
  - 공인시험 데이터가 '기준점(앵커) 허브'로서 새 가치를 얻습니다.
  - 2024 KoMaP 내광성 등급 예측 같은 과제에 "재현성이 허용하는 최대 정확도"를 먼저 제시해 과대평가를 막습니다.
- **연구자**:
  - 문헌 메타분석과 AI 모델의 일반화 성능을 정직하게 보고할 수 있습니다.
  - 실패 기록이 학술적 크레딧이 됩니다.
- **참가자 연구 쪽**: 비대칭 수분이동 막처럼 시험법이 난립한 분야에서 비교 가능한 데이터셋을 만드는 첫 단계가 됩니다.

### 확장성
- 시험법·소재 계열이 늘어도 같은 틀(감사 → 분해 → 기준시료 → 기탁)을 그대로 씁니다.
- 염색 견뢰도(ISO 105 계열 반급 등급), 인장(KS K ISO 13934), 공기투과도(ISO 9237)로 확장할 수 있습니다.
- 기업 원자료 대신 기준시료 요약통계만 공유하는 방식(연합식)과도 호환됩니다.
- 시험법 카드가 비어 있는 과거 문헌은 Methods 텍스트를 메타데이터 대리로 쓰는 방식(DATUM의 발상)으로 보완할 수 있습니다. 다만 이는 신규 모델 개발이 필요하므로 장기 확장으로 둡니다.

### 한계
- 방법론 요소는 모두 기존 기법입니다. ISO 5725, 계층 베이지안 실험실 효과, 검량 이전(calibration transfer), 그룹 교차검증이 그렇습니다. 새로운 것은 섬유 데이터에의 적용과 운영 규칙화입니다.
- 공통 시료가 없는 문헌 데이터에서는 '출처 효과'에 실험실 편향, 미보고 변수(Mw, 습도 등), 탐색 영역 차이가 섞입니다. 그래서 "재현성"이라 부르지 않고 **"보고된 변수 조건부 출처 간 분산"**으로 표기합니다.
- PoC의 '기준점'은 같은 논문의 다른 측정점이지 물리적 기준시료가 아닙니다. 물리 기준시료 검증은 DYETEC·본인 데이터가 있어야 가능합니다.
- PoC 데이터가 주로 나노섬유·기체투과이고, 섬유 원단 시험데이터는 염색 1건뿐입니다.

### 6.2 가장 치명적인 약점 3가지와 대응
1. **'출처 효과'가 실험실 편향인지, 미보고 변수와 탐색 영역 차이(공변량 이동)인지 분리되지 않습니다.**
   - 대응 1: 같은 조건(근접 조건) 쌍 분석을 직접 증거로 제시합니다. 전기방사에서 다른 논문의 거의 같은 조건 51쌍의 직경 차이 중앙값이 1.55배였습니다.
   - 대응 2: 표현을 "보고된 변수 조건부 출처 간 분산"으로 낮춥니다.
   - 대응 3: 물리 기준시료(DYETEC 숙련도시험 시료, 본인 반복측정)로 분리하는 계획을 제시합니다.
2. **섬유 원단·공인시험 데이터 PoC가 약합니다.** 염색 1건뿐이고 나머지는 나노섬유·기체투과입니다.
   - 대응 1: 10/21 전에 McCullough 2003의 26×5 표를 디지타이즈해 증기 시험법 등화를 소규모로 실증합니다.
   - 대응 2: 가능하면 KoMaP 2024 경진대회 데이터(염색·내광성)나 본인 Janus 막 측정치를 붙입니다.
   - 대응 3: 막지 못하면 "섬유 시험데이터 적용은 다음 단계"라고 명시합니다.
3. **"이미 하는 일(숙련도시험)" 또는 "데이터 정제일 뿐"이라는 반론이 나올 수 있습니다.**
   - 대응 1: 숙련도시험은 미래의 계획된 비교입니다. 이 컨셉은 과거 누적 데이터의 사후 재활용과 새 데이터의 합류 규칙이라는 점을 분명히 합니다.
   - 대응 2: 정제가 아니라 "AI 일반화 성능이 실제로 회복된다"(기준점 3점에서 R² 0.05→0.42)를 정량 결과로 앞세웁니다.

### 6.3 반증 조건 (이 결과가 나오면 아이디어가 틀린 것)
- **F1**: 대상 데이터(예: DYETEC 시험데이터)에서 출처 단위 교차검증 오차가 무작위 교차검증 오차와 비슷하고(차이 10% 미만), 출처 오프셋 분산 비중이 10% 미만이면 핵심 전제가 성립하지 않습니다. 참고로 단일 기관의 표준조건 데이터라면 그럴 수 있습니다.
- **F2**: 기준시료 k≤5로 보정해도 새 출처의 오차가 줄지 않으면 합류 프로토콜이 무용합니다. 판정 기준은 출처별 개선 비율 70% 미만이거나, 개선의 95% 신뢰구간이 0을 포함하는 경우입니다.
- **F3**: 감사 플래그를 써서 학습데이터를 거르거나 가중해도 출처 단위 일반화 오차가 개선되지 않으면(신뢰구간이 0 포함), 감사는 '위생'일 뿐 예측 가치가 없습니다.
- **F4**: 다른 고분자·공정에서 실패 포함 모델과 성공만 쓴 모델의 실패 탐지 AUC 차이가 신뢰구간상 0과 구별되지 않으면, 실패 데이터의 가치 주장이 무너집니다.
- **F5 (확장 1)**: 시험법 하나를 빼고 검증한 환산 오차가 직물 간 표준편차 이상이면 환산표가 무용합니다.

### 8.2 핵심 가정을 확인하는 통계·계산 검증 설계
1. **교차검증 방식**
   - 무작위 k-fold, 출처 단위(leave-one-source-out), 고분자·계열 단위, 시간 분할(출판연도)을 모두 보고합니다.
   - 같은 계보는 같은 폴드에 둡니다.
   - 차이(일반화 격차)에는 출처 단위 부트스트랩 95% 신뢰구간을 붙입니다.
2. **분포 외(OOD) 일반화 테스트**
   - 계열 하나를 통째로 빼고 k-shot(k=0/3/5/10)을 시험합니다.
   - 새 출처에 기준점 k를 줄 때의 회복 곡선을 그립니다.
   - 탐색 영역의 겹침(최근접 거리)으로 층화해 보고합니다.
3. **대조군 모델**
   - 평균 예측, 출처 평균 예측(출처만 아는 모델), 무작위 소스, 라벨을 섞은 소스(순열), 무작위 트리, 지문 최근접을 둡니다.
   - 아이디어의 효과는 이 대조군들을 이겨야 인정합니다.
4. **불확실성 평가**
   - 출처 랜덤효과의 사후분포(계층 베이지안)를 구합니다.
   - 출처 단위 conformal 예측구간과 그 커버리지를 확인합니다.
   - 노이즈 천장은 같은 조건 쌍의 σ에서 R²_max로 계산합니다.
5. **다중비교 통제**
   - 소스·설정 탐색은 사전에 정하고(사전등록), 선택과 평가는 중첩 교차검증으로 나눕니다.
   - 소표본에서 최고 소스를 고를 때는 순열 대조군의 95% 분위수를 넘어야 채택합니다.
6. **인공 오류 주입**
   - 단위 ×10, 온도 뒤바꿈, 중복 삽입을 넣어 감사 규칙의 재현율과 정밀도를 측정합니다.
   - 다만 규칙이 잡도록 설계된 오류로 규칙을 검증하는 순환이 생기므로, 원문 대조 표본 50건으로 따로 확인합니다.
