# VRR v2 사전등록(pre-registration): 가설·검증 절차·합격 기준

- 작성: 2026-10-07. 모델링 결과를 보기 전에 이 파일을 git에 커밋해 시점을 고정합니다.
- 대상 컨셉: **가상 라운드로빈(Virtual Round-Robin, VRR)**. 섬유·고분자 소재데이터의 출처를 진단하고, 기준시료(앵커)로 새 출처를 합류시키는 체계입니다.
- 원칙
  - 아래 기준은 결과를 본 뒤 바꾸지 않습니다.
  - 기준을 벗어난 분석은 모두 `EXPLORATORY`로 표시합니다.
  - 절차를 바꾸면 ledger에 사유를 남깁니다.
  - 실패·불합격도 전부 보고합니다.

## 2. 가설과 합격 기준

### H1 평가 과대: 무작위 CV는 새 출처 성능을 과대평가한다
- 절차
  - 무작위 5-fold와 출처 GroupKFold(min(10, 출처 수))를 비교합니다. 시드 5개, 모델 RF·GB·KNN.
  - 음성 대조: 행을 실제 출처 크기 분포대로 무작위 '가짜 출처'로 나눈 GroupKFold(20 시드).
  - DES_RHO·DES_ETA는 원자료와 계보 정리본을 둘 다 봅니다.
- 지표: gap = RMSE_group / RMSE_random − 1
- 데이터셋별 합격: 세 조건을 모두 만족해야 합니다.
  - RF gap ≥ 0.20
  - 실제 gap > 가짜 출처 gap의 95번째 백분위
  - 다른 모델 1종 이상에서 gap ≥ 0.10
- 전체 판정: 7개 중 5개 이상이면 PASS, 3개 이하면 FAIL, 나머지는 PARTIAL
- 진단용(채점 안 함): 소재 단위 CV(leave-material-out)

### H2 같은 시료·같은 조건에서 출처 간 불일치가 있고, 그 크기는 물성마다 다르다
- 절차
  - 복사 관계를 제외한 독립 출처 쌍의 동일 키 차이에서 σ_between = median|Δ| / (0.6745·√2)를 구합니다.
  - 노이즈 천장 R²_ceiling = 1 − σ²_between / Var(y)
  - ES1은 v1 근접조건 쌍 정의로 재현합니다.
- 사전 예측
  - P2a: DES_RHO 독립 출처 간 |Δρ| 중앙값 ≤ 0.010 g/cm³ (밀도는 재현성이 좋다)
  - P2b: DES_ETA 독립 출처 간 배수 차이 중앙값 ≥ 1.10배 (점도는 수분 등 미보고 변수에 민감하다)
  - P2c: σ_between / SD(y)가 DES_RHO < DES_ETA
- 합격: 3개 중 2개 이상

### H3 출처 오프셋은 출처의 안정된 속성이다 (앵커 프로토콜의 전제)
**H3a 반분 신뢰도(split-half reliability)**
- 대상: 10행 이상인 출처가 8개 이상인 데이터셋
- 절차
  - 출처 밖 잔차를 구합니다(GroupKFold 10, RF, 누수 복사본 제거).
  - 출처마다 행을 둘로 나눠 반쪽 평균잔차의 출처 간 상관을 구하고, Spearman–Brown 보정합니다. 무작위 분할 50회를 평균합니다.
  - 분할 방식은 둘입니다: ① 행 무작위, ② **소재가 겹치지 않게 분할(엄격, 채점용)**. 소재가 2종 미만인 출처는 ①을 씁니다.
- 귀무: 잔차를 출처 무관하게 섞은 순열 200회
- 데이터셋별 합격: R ≥ 0.5, CI 하한 > 0, R > 귀무 95번째 백분위
- 전체 판정: 해당 데이터셋 중 4개 이상이면 PASS

**H3b 물리 기준시료 전이**
- 대상: DES_RHO, DES_ETA
- 기준시료: ChCl:요소, ChCl:EG, ChCl:글리세롤 1:2(x_ChCl ≈ 1/3)
- 절차: 기준시료와 다른 소재를 함께 잰 출처에서, 기준시료 잔차 평균과 다른 소재 잔차 평균의 Spearman ρ를 구합니다. 순열 5,000회로 p값을 냅니다.
- 합격: 2개 데이터셋 중 1개 이상에서 ρ ≥ 0.3이고 p < 0.05

### H4 기준점 k개로 새 출처를 합류시킬 수 있다
- 대상: 8행 이상 출처가 8개 이상인 데이터셋(ES1, ES2, DES_RHO, DES_ETA, DES_MP, IL_CELL). DYE는 기술통계만 냅니다.
- 절차
  - 출처 s를 뺀 학습(누수 복사본 제거)으로 s를 예측합니다.
  - k ∈ {0,1,2,3,5}, 무작위 앵커 30회. 앵커 행은 평가에서 뺍니다.
- 방법
  - OFF: 앵커 잔차 평균
  - SHR: 경험적 베이즈 수축 오프셋 kτ²/(kτ²+σ²). τ², σ²는 s를 제외한 학습 출처의 출처 밖 잔차로 추정합니다.
  - RET: 앵커를 넣고 재학습. 가중치 5, 5회. 계산량 때문에 행 수 ≤ 1,000 데이터셋 또는 출처 30개 표본에서만 합니다.
- 대조
  - FAKE: 다른 무작위 출처의 k행으로 오프셋 계산
- 지표
  - 출처별 RMSE_k / RMSE_0 − 1을 출처 평균으로 냅니다(출처 부트스트랩 CI).
  - 개선된 출처 비율
  - 격차 회복률 = (RMSE_0 − RMSE_k) / (RMSE_0 − RMSE_randomCV)
- 데이터셋별 합격: 세 조건을 모두 만족해야 합니다.
  - OFF 또는 SHR의 k=3 평균 변화 ≤ −10%
  - CI 상한 < 0
  - FAKE k=3 평균 변화 ≥ −2%
- 전체 판정: 6개 중 4개 이상이면 PASS
- 부가 예측: SHR k=1이 k=0보다 나쁘지 않음(평균 변화 ≤ 0). 6개 중 4개 이상 성립하면 합격

### H5 감사 규칙
감사 규칙(사전 고정)
- R1 물리 범위
  - 밀도 0.5–3.0 g/cm³
  - 점도 0.2 cP – 1e7 cP
  - 직경 10 nm – 50 µm
  - 온도 150–500 K
- R2 강건 z: 같은 소재 그룹(3행 이상)의 MAD 기준 |z| > 5, 또는 출처 밖 CV 잔차의 강건 |z| > 5
- R3 복사 탐지: 같은 키와 같은 값이 다른 출처에 있음
- R4 기본값 쏠림: 한 출처의 조건 열에서 40% 넘는 행이 데이터셋 최빈값과 같은 값

**H5a 인공 오류 주입**
- 대상: 계보 정리본 DES_RHO, DES_ETA, 그리고 ES1
- 주입: 오류 유형별로 5% 행, 10 시드
  - UNIT: 밀도 ×1000, 점도 ×0.001(cP→Pa·s), 직경 ×0.001
  - TEMP: K→°C
  - COPY: 다른 출처 행을 출처명만 바꿔 복제
  - DEFAULT: 조건을 상수로(DES T=298.15, ES1 습도=45)
- 지표
  - 유형별 재현율·정밀도
  - 깨끗한 평가행에서의 출처 단위 RMSE: 원본 / 주입 / 주입 후 감사 필터링
  - 회복률 = (주입 − 필터) / (주입 − 원본)
- 합격: 세 조건을 모두 만족해야 합니다.
  - UNIT·TEMP 재현율 ≥ 0.8, 정밀도 ≥ 0.8
  - COPY 재현율 ≥ 0.9
  - UNIT·TEMP 회복률 ≥ 50%(3개 데이터셋 모두)
- DEFAULT는 탐색적입니다(낮은 재현율을 예측).
- 한계: 규칙이 잡도록 설계된 오류로 규칙을 검증하는 순환이 있습니다.

**H5b 실제 데이터에서 감사의 예측 가치**
- 대상: 7개 데이터셋
- 절차: 플래그가 붙은 행을 뺀 학습과 전체 학습을 비교합니다. 평가는 미플래그 행만, 출처 단위로 합니다.
- 합격: 2개 이상 데이터셋에서 RMSE 개선의 CI 상한 < 0
- 사전 예측: **FAIL 가능성이 높음**. 감사의 가치는 정확도보다 신뢰 표시에 있을 것으로 봅니다.

### H6 계보(복사)와 큐레이션 재현성
- H6a: DES_RHO, DES_ETA에서 복사본이 학습에 남아 있을 때의 출처 단위 RMSE를, 제거했을 때와 비교합니다.
  - 합격: 1개 이상 데이터셋에서 변화 ≤ −10%이고 CI 상한 < 0. 즉 복사본 때문에 평가가 10% 이상 좋게 보이는 경우입니다.
- H6b: 무작위 CV RMSE를 원자료와 계보 정리본에서 비교합니다(기술통계).
- H6c 큐레이션 라운드로빈: ES1과 ES2에 동시에 있는 PVDF 논문(DOI 일치)에서 같은 조건 행의 값 일치율, 한쪽에만 있는 행 수, |Δlog10 D|를 구합니다(기술통계).

### H7 실패 데이터의 가치: 성공만 있는 데이터로는 실패를 예측할 수 없다
- H7a ES1 PVDF
  - 실패 논문 하나 빼기(10편)
  - 단일 클래스 모델: IsolationForest, OneClassSVM, kNN 거리
  - 지도학습 모델: RF, HistGB
  - 시드 5개, 논문 부트스트랩 CI
- H7b DES 재현
  - 실패 = DES_MP 녹는점 > 298.15 K
  - 단일 클래스 모델: '성공 DB'(DES_RHO ∪ DES_ETA의 소재, 즉 상온 액체로 측정된 것)로 학습
  - 지도학습 모델: DES_MP 라벨로 출처 GroupKFold
  - 학습곡선: 실패 라벨 수 5/10/20/50/100/전체
- 합격: H7a와 H7b 모두에서 (최선 지도학습 − 최선 단일 클래스) AUC ≥ 0.10이고 CI 하한 > 0

### H8 연계 게이트: 데이터 기반 점수와 순열 문턱으로 음전이를 막는다 (중첩 검증)
- 데이터: polyVERSE 소규모 타깃 11개
- 소스 풀: 소스 12개 이상. 무관 물성과 라벨 순열 소스를 포함합니다.
- 절차
  - 외부 5-fold × 3회
  - 내부(외부 학습분만 사용)에서 교차적합 소스 예측과 타깃 라벨의 상관을 점수로 씁니다.
  - 순열 소스 점수의 95번째 백분위를 문턱으로 씁니다.
- 정책 비교
  - NONE: 연계 안 함
  - PHYS: 사전 지정한 물리 직관 소스
  - TOP: 최고 점수 소스(게이트 없음)
  - GATE: 문턱을 넘는 경우에만 최고 점수 소스
  - ALL3: 상위 3개 동시
- 합격: 세 조건을 모두 만족해야 합니다.
  - GATE 음전이(이득 < −1%) 타깃 ≤ 1/11
  - GATE 평균 이득 > 0
  - GATE 음전이율 < TOP 또는 PHYS의 음전이율

### H9 신뢰 라벨: 출처를 아는 예측구간만 새 출처에서 보장된다
- 절차
  - 외부 출처 GroupKFold(10), RF
  - 보정 잔차를 두 방식으로 구합니다. (i) 무작위 5-fold(순진한 방식) (ii) 출처 GroupKFold(출처 인식)
  - 90% 분위수로 예측구간을 만듭니다.
  - (iii) 앵커 보정 구간: 8행 이상 출처에서 k=3 앵커 오프셋을 반영하고, 보정 단계에서도 같은 절차를 모사합니다.
- 합격: 세 조건을 모두 만족해야 합니다.
  - 순진한 방식의 새 출처 커버리지 < 0.85인 데이터셋이 7개 중 4개 이상
  - 출처 인식 방식의 커버리지 ≥ 0.87인 데이터셋이 5개 이상
  - 앵커 보정 구간 폭이 출처 인식 대비 ≤ 0.9배이고 커버리지 ≥ 0.87인 데이터셋이 3개 이상

## 3. 컨셉 판정 규칙
- **핵심 사슬**: H1(문제 존재) → H3(오프셋 안정) → H4(앵커 회복) → H9(신뢰 라벨)
  - 4개 모두 PASS면 "공개 데이터로 입증됨"
  - 3개 PASS면 "부분 입증"
  - 그 이하면 컨셉을 재설계
- **모듈**: H2(진단), H5(감사), H6(계보), H7(실패), H8(게이트)
  - FAIL한 모듈은 주장에서 빼거나 재정의합니다.
- **v1에서 이미 기각된 것(재실행 안 함, 음성 결과로 유지)**
  - 징검다리 체인(P9)
  - 소재 계통수의 예측 가치(P10)
  - 물리 직관 전이 점수(P8)
